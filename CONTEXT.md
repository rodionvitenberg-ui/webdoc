# Domain Glossary — WebDoc.life (Checkups)

Единый язык проекта для людей и кода. Термины, которые все должны понимать одинаково.

## Основные понятия

| Термин | Значение | Комментарий |
|--------|----------|-------------|
| **Анализ** `MedicalAnalysis` | Один загруженный бланк лабораторного исследования (PDF/фото) + его расшифровка | Жизненный цикл: pending → processing → completed/failed. |
| **Пересчёт (reanalyze)** | Повторная интерпретация того же бланка с обновлённым контекстом паци-ента | Создаёт новую запись Анализа с `parent_analysis` на исходный. |
| **Показатель** `AnalysisIndicator` | Отдельная атомарная метрика (например, гемоглобин, лейкоциты) с датой | Выделяется из `ai_result`; используется для графиков динамики. |
| **Результат ИИ** `ai_result` | Структурированный JSON, возвращённый интерпретатором: reasoning, summary, indicators, causes, recommendations | Хранится на Объекте Анализа. |
| **Профиль (пациент)** `PatientProfile` | Карточка человека: ФИО, пол, дата рождения, вес, рост | Принадлежит одному Пользователю; либо является «сиротой». |
| **Орфан-профиль (сирота)** | Профиль без владельца (`user=null`), создан гостем при загрузке | «Усыновляется» при claim. |
| **Пользователь** `User` | Владелец аккаунта (вход по email) | Может иметь несколько Профилей. |
| **Профиль по умолчанию** | Первый созданный профиль пользователя (после регистрации) | Не удаляется; используется как фолбэк. |
| **Claim (привязка)** | Гостевой флоу: указание email + код/пароль, чтобы привязать Орфан-анализ к Пользователю | Один эндпоинт запрашивает, другой верифицирует. |
| **Характеристика** `Trait` | Справочник черт: заболевания, вредные/полезные привычки, особенности | и системные, и кастомные (пользовательские). |
| **Связь характеристики** `PatientTraitLink` | Привязка конкретной Характеристики к Профилю с деталями (стаж, дозировка) | unique (patient, trait). |
| **Чат (по анализу)** `ChatMessage` | Переписка пользователя с ИИ-ассистентом по конкретному Анализу | Старые сообщения архивируются в `chat_summary`. |
| **Сводка чата** `chat_summary` | Кратное содержание прошедших обсуждений (архив для экономии токенов) | Перегенерируется фоновой задачей. |
| **Лимит (дневной)** | Максимум «запусков ИИ» для пользователя в сутки | FREE=5, PRO=10. Считается по реально запущенным/завершённым анализам. |
| **PRO-подписка** | Временный статус `is_pro`, дающий повышенные лимиты | активируется после успешной оплаты. |
| **Транзакция** `Transaction` | Запись о платёжном намерении/факте через Cryptomus | pending → paid/fail. |

## Часто смешиваемые термины

- **«Анализ» (документ)** ≠ **«Показатель» (метрика)**: Анализ — это загруженный бланк; Показатель — один атомарный результат из расшифровки.
- **«Решение ИИ»** — это Анализ в статусе completed, а не `ai_result` отдельно.
- **«Пересчёт»** — копия Анализа с привязкой к родителю, а не мутация исходного.
- **«Профиль»** — карточка человека (может быть орфаном), не синоним «пользователя».
